VitaStore

Vision
Каждый купленный магазин увеличивает прибыль. Купленный магазин становится типовой точкой за 5 дней с доступом ко всему ассортименту склада. 

Strategy
Автоматическое сопоставление товаров, подключение магазинов без выезда ИТ бригады. Типовые сервисы приобретать как сервис (SaaS). Уникальные остаются внутри. Отказаться от локальных серверов, программный стек не зависит от  унаследованных терминалов и фискальных регистраторов

Architecture
Бэкенд кассы вынесен в облачное приложение, в магазине легкое приложение с локальным хранилище и прослойка (HAL/Gateway) для интеграции с железом. Облачны POS взаимодействует с ERP по REST API.  Система автоматического маппинга с оценкой уверенности выше 95% автоматически привязыает к позиции, остальное на товароведа.  В магазине только планшет, терминал и фискальный регистратор.

Implemenatation
-

Бизнес драйверы: рост через поглащение оффлайн магазинов убыточен, расходы растут с каждой оффлайн точки - серверы, лицензии, выезды инженеров. Подключение магазина занимает 2-3 недели и держится полностью на ручном труде.  Ограничения - разнородные терминалы и требования обеспечить продажи за наличные при отсутствии интеренета.

Бизнесцель: Переход завершить через год,  снизить TCO обслуживания ИТ инфраструктуры магазина на 40% на горизонте 3-ех лет. Через год сократить время ввода нового магазина с 14 до 5 дней. Повысить качество маппинга: ошибок на кассе не более 2% (не читается штрих код или не та цена )
